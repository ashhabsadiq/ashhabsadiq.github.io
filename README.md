# ashhabsadiq.github.io

Source code for the personal academic portfolio of **Md. Ashhab Sadiq**, an urban and regional planner working with GIS, remote sensing and machine learning on land use, climate and environmental questions in Bangladesh.

**Live site:** https://ashhabsadiq.github.io

## What's inside

The site is a single home page plus ten detailed case-study pages.

- **Home page** (`index.html`): about, education, research and publications, work experience, academic projects, skills, awards, certifications, extracurricular activities and contact links.
- **Research case studies** (`research-*.html`): four published studies, each with its study area, methodology, maps and key findings.
  - Meteorological drought assessment in northern Bangladesh (*Ecological Indicators*)
  - Groundwater vulnerability assessment in Bangladesh (*Groundwater for Sustainable Development*)
  - Students' perception of environmental sustainability in universities (*Frontiers in Engineering and Built Environment*)
  - Community-based approach using participatory rural appraisal (ICACE-2024)
- **Studio projects** (`academic-*.html`): six planning studio projects from the BURP programme at KUET, covering regional, environmental, transportation, rural, urban and site planning.

## How it's built

Plain HTML, CSS and JavaScript, with no framework and no build step. GitHub Pages serves the files directly from the `main` branch.

| Path | Purpose |
|---|---|
| `style.css` | All styling, including the light and dark themes |
| `script.js` | Theme switch, section menu, image viewer and scroll highlighting |
| `icons.svg` | Icon set used across the pages |
| `Images/` | Original maps, figures, certificates and photos |
| `Images/web/`, `Images/thumb/` | Compressed WebP copies used on the pages for faster loading |

The site adapts to phones, tablets and desktops, and it follows the visitor's light or dark preference.

## Usage

The maps, figures, certificates and written content belong to Md. Ashhab Sadiq and the co-authors of the listed publications. Please don't reuse them without permission. To cite the research, use the publication links on each case-study page.

The home page background is a satellite image of the Sundarbans by NASA Earth Observatory (public domain).
